Entry for the make.fun bounty **One Line of Earned Pride** — a single line of
text, 1 to 240 characters, giving the judge a quiet, earned moment of pride
for someone in a scene.

`main.py` writes one line to `/output/entry.txt`:

> On her third try, seven-year-old Ana threaded the needle, sewed the button back onto her father's coat, and held it up like a flag she'd sewn herself.

Run it with `python3 main.py`. The output is deterministic.
